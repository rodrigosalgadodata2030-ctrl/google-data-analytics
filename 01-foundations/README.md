# Análisis del tiempo de espera de pacientes

## Proyecto 1 — Tiempo de espera y satisfacción

### Objetivo

Analizar la relación entre el tiempo de espera de los pacientes y su nivel de satisfacción.

### Datos

Conjunto de datos simulado de 50 pacientes de una clínica de fisioterapia.

### Variables

- ID del paciente
- Edad
- Tipo de tratamiento
- Número de sesiones
- Tiempo de espera
- Nivel de satisfacción
- Recomendaría la clínica

### Análisis realizado

Se utilizó Microsoft Excel para organizar los datos y crear un gráfico de dispersión para analizar la relación entre el tiempo de espera y la satisfacción del paciente.

### Hallazgo

Los datos muestran una relación negativa: los pacientes con menores tiempos de espera tienden a presentar mayores niveles de satisfacción.

### Conclusión

Reducir los tiempos de espera podría contribuir a mejorar la satisfacción de los pacientes.

## Proyecto 2 — Análisis de tratamientos

### Objetivo

Analizar la relación entre el tipo de tratamiento, el número promedio de sesiones y la satisfacción promedio de los pacientes.

### Datos

Se utilizaron los mismos datos de 50 pacientes de una clínica de fisioterapia.

### Análisis realizado

Se calculó el número promedio de sesiones y la satisfacción promedio para cada tipo de tratamiento mediante Microsoft Excel.

### Resultados

| Tratamiento | Sesiones promedio | Satisfacción promedio |
|---|---:|---:|
| Sports | 5,86 | 4,50 |
| Musculoskeletal | 7,73 | 3,67 |
| Neurological | 12,50 | 2,58 |
| Remedial Massage | 5,89 | 4,78 |

### Pregunta

¿Existe una relación entre el número promedio de sesiones y la satisfacción promedio según el tipo de tratamiento?

### Visualización

Se utilizó un gráfico de dispersión (Scatter) para analizar la relación entre las sesiones promedio y la satisfacción promedio.

### Hallazgo

Los datos muestran una tendencia negativa: los tratamientos con un mayor número promedio de sesiones tienden a presentar una menor satisfacción promedio.

### Conclusión

En estos datos, Neurological presenta el mayor número promedio de sesiones (12,50) y la menor satisfacción promedio (2,58), mientras que Remedial Massage presenta una de las menores cantidades de sesiones promedio (5,89) y la mayor satisfacción promedio (4,78).

### Herramientas utilizadas

- Microsoft Excel
- PROMEDIO.SI / AVERAGEIF
- Análisis de datos
- Visualización de datos
