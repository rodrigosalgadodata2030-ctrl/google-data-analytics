# Análisis del tiempo de espera de pacientes

## Objetivo

Analizar la relación entre el tiempo de espera de los pacientes y su nivel de satisfacción.

## Datos

Conjunto de datos simulado de 50 pacientes de una clínica de fisioterapia.

## Variables

- ID del paciente
- Edad
- Tipo de tratamiento
- Número de sesiones
- Tiempo de espera
- Nivel de satisfacción
- Recomendaría la clínica

## Análisis realizado

Se utilizó Microsoft Excel para organizar los datos y crear un gráfico de dispersión que permitiera analizar la relación entre el tiempo de espera y la satisfacción del paciente.

## Hallazgo principal

Los datos muestran una relación negativa entre ambas variables: los pacientes con menores tiempos de espera tienden a presentar mayores niveles de satisfacción.

## Herramientas utilizadas

- Microsoft Excel
- Análisis de datos
- Visualización de datos

## Conclusión

Reducir los tiempos de espera podría contribuir a mejorar la satisfacción de los pacientes.

## Aprendizaje

Este proyecto permitió aplicar conceptos básicos de análisis de datos, organización de información, identificación de relaciones entre variables y comunicación de resultados.

## Proyecto 2 — Satisfacción según tipo de tratamiento

### Pregunta

¿Qué tipo de tratamiento presenta el mayor nivel promedio de satisfacción?

### Análisis

Se calculó la satisfacción promedio de los pacientes según el tipo de tratamiento.

### Resultados

- Sports: 4,50
- Musculoskeletal: 3,67
- Neurological: 2,58
- Remedial Massage: 4,78

### Hallazgo

Remedial Massage presenta la mayor satisfacción promedio (4,78), seguido de Sports (4,50). Neurological presenta el promedio más bajo (2,58).

### Conclusión

En estos datos, Remedial Massage y Sports presentan mayores niveles de satisfacción promedio que Musculoskeletal y Neurological.

- Microsoft Excel
- PROMEDIO.SI
- Análisis de datos
- Visualización de datos
