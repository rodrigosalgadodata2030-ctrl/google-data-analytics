# Análisis de pacientes de una clínica de fisioterapia

## Datos

Conjunto de datos simulado de 50 pacientes de una clínica de fisioterapia.

### Variables

- ID del paciente
- Edad
- Tipo de tratamiento
- Número de sesiones
- Tiempo de espera
- Nivel de satisfacción
- Recomendaría la clínica

---

# Proyecto 1 — Tiempo de espera y satisfacción

## Pregunta

¿Existe una relación entre el tiempo de espera y la satisfacción del paciente?

## Análisis

Se analizó la relación entre el tiempo de espera y el nivel de satisfacción de los pacientes mediante un gráfico de dispersión (Scatter).

## Hallazgo

Los datos muestran una relación negativa entre ambas variables: los pacientes con menores tiempos de espera tienden a presentar mayores niveles de satisfacción.

## Conclusión

Reducir los tiempos de espera podría contribuir a mejorar la satisfacción de los pacientes.

---

# Proyecto 2 — Satisfacción según tipo de tratamiento

## Pregunta

¿Qué tipo de tratamiento presenta el mayor nivel promedio de satisfacción?

## Análisis

Se calculó la satisfacción promedio de los pacientes para cada tipo de tratamiento utilizando Microsoft Excel.

## Resultados

| Tipo de tratamiento | Satisfacción promedio |
|---|---:|
| Sports | 4,50 |
| Musculoskeletal | 3,67 |
| Neurological | 2,58 |
| Remedial Massage | 4,78 |

## Hallazgo

Remedial Massage presenta la mayor satisfacción promedio (4,78), seguido de Sports (4,50). Neurological presenta el promedio más bajo (2,58).

## Conclusión

En estos datos, Remedial Massage presenta el mayor nivel promedio de satisfacción.

---

# Proyecto 3 — Sesiones y satisfacción

## Pregunta

¿Qué relación existe entre el número promedio de sesiones y la satisfacción de los pacientes según el tipo de tratamiento?

## Análisis

Se calculó el número promedio de sesiones y la satisfacción promedio para cada tipo de tratamiento utilizando Microsoft Excel.

## Resultados

| Tipo de tratamiento | Sesiones promedio | Satisfacción promedio |
|---|---:|---:|
| Sports | 5,86 | 4,50 |
| Musculoskeletal | 7,73 | 3,67 |
| Neurological | 12,50 | 2,58 |
| Remedial Massage | 5,89 | 4,78 |

## Visualización

Se utilizó un gráfico de dispersión (Scatter) para analizar la relación entre las sesiones promedio y la satisfacción promedio.

## Hallazgo

Los datos muestran una tendencia negativa: los tratamientos con un mayor número promedio de sesiones tienden a presentar una menor satisfacción promedio.

## Conclusión

Neurological presenta el mayor número promedio de sesiones (12,50) y la menor satisfacción promedio (2,58), mientras que Remedial Massage presenta 5,89 sesiones promedio y la mayor satisfacción promedio (4,78).
